# Student Grade Calculator

A simple, responsive web application designed to calculate student marks, percentages, and overall grades across five subjects.

## 🚀 Features
* Enter student name and marks for 5 individual subjects.
* Instantly calculate total marks, percentage, and corresponding grades.
* Clean, user-friendly interface with reset and result options.

## 🛠️ Built With
* HTML5
* CSS3 / Tailwind CSS (or Custom CSS)
* JavaScript
